# 1. 背景与目标

现有AI学习工具普遍存在三个问题：功能入口分散（画像、资源、答疑各自独立页面）、操作流程复杂（用户需在多个页面间跳转）、学习与日程割裂（AI生成的计划无法直接落地到日历）。

本项目目标：在时纪流（ChronoFlow）日程管理系统基础上，基于科大讯飞星火大模型搭建**智流（MindFlow）**多智能体个性化学习体系。所有AI学习功能统一集成于APP发现页的**统一对话界面**，用户通过纯自然语言完成画像构建、资源生成、学习规划、智能答疑、效果评估全流程，生成的资源以**云盘形式**持久化管理，学习任务一键同步至日历，实现"时间管理+个性化学习"一体化。

# 2. 目标用户

18-26岁在校学生（课业、考研、零基础自学群体），具备基础手机操作能力，无技术门槛。适配个人学习、班级/小组协作场景。仅覆盖计算机/人工智能类高校专业课程。

典型需求示例：

- "帮我生成机器学习决策树的学习资料"
- "我要在30天内学完数据结构，每天能学2小时"
- "什么是卷积神经网络的反向传播？"
- "查看我的学习报告"
- "把今天的任务同步到日历"

# 3. 核心功能

## 3.1 发现页

发现页位于底部导航【发现】tab，页面仅包含两个卡片入口：

- 【AI学习系统】→ 进入统一对话界面
- 【我的云盘】→ 进入资源云盘页面

页面结构简洁清晰，无其他多余内容。

## 3.2 统一对话界面

点击【AI学习系统】卡片进入统一对话界面，所有AI学习功能均在同一窗口中完成。

**交互方式**：纯自然语言，系统自动识别用户意图并切换功能模块。

**功能入口**：
- 对话界面右上角设有使用指导小图标，点击进入静态使用说明页面
- 画像功能通过"查看画像"、"更新画像"等指令调用
- 学习报告通过"查看学习报告"指令调用
- 日历同步通过"同步到日历"指令执行

**输出形式**：AI回复在对话流中展示，包含文字、可视化卡片、图解等；日历同步结果直接在对话中返回。

## 3.3 六维学习画像

**输入**：用户通过对话问答，回答学习基础、认知风格、学习节奏、薄弱知识点、学习目标、易错类型等问题。

**输出**：六维可视化学习画像卡片，在对话中展示。

**流程**：
1. 用户输入"开始学情测评"，系统启动画像构建对话
2. 系统通过自然语言问答引导用户回答六维问题
3. 系统自动提取特征，生成可视化画像卡片
4. 用户可随时输入"查看画像"查看当前画像，或输入"更新画像"重新测评

**六维指标**：知识基础、认知风格、学习节奏、薄弱知识点、学习目标、易错类型

## 3.4 多智能体资源生成

**输入**：用户在对话中描述知识点/薄弱点/学习需求。

**输出**：五类个性化学习资源，流式输出至对话界面，同时自动存储至云盘。

**流程**：
1. 用户描述需求，例如"帮我生成机器学习决策树的学习资料"
2. 系统识别意图，调用多智能体协同生成
3. 流式输出五类资源：讲解文档、思维导图、专项习题、拓展材料、代码案例
4. 资源自动存储至服务器数据库，用户可在云盘中查看

**多智能体架构**：不同角色Agent（讲解Agent、思维导图Agent、出题Agent、拓展Agent、代码Agent）协同完成资源生成，实现千人千面适配。

## 3.5 AI智能学习规划

**输入**：用户在对话中描述学习目标和每日可用学习时长。

**输出**：阶梯式学习路线与每日任务清单，在对话中展示。

**流程**：
1. 用户描述目标，例如"我要在30天内学完数据结构，每天能学2小时"
2. 系统结合用户画像、知识点依赖关系生成学习计划
3. 用户可输入"同步到日历"将任务同步至系统日历
4. 系统根据完成情况自动优化后续计划

## 3.6 多模态智能答疑

**输入**：用户在对话中直接输入问题。

**输出**：分步文字解析 + 可视化图解（流程图、时序图等），在对话中展示。

**流程**：
1. 用户提问，例如"什么是卷积神经网络的反向传播？"
2. 系统拆解问题逻辑，分步输出文字解析
3. 复杂知识点自动生成可视化图解
4. 用户可追问"再详细解释一下"深入探讨

## 3.7 学习效果评估

**输入**：系统自动采集用户学习行为数据（资源学习、习题练习、答疑互动）。

**输出**：学习分析报告（知识掌握度、薄弱点、学习效率），在对话中展示。

**流程**：
1. 系统实时采集全量学习行为数据
2. 周期性自动生成学习分析报告
3. 用户输入"查看学习报告"获取最新报告
4. 系统根据评估结果自动调整资源难度和学习计划

## 3.8 我的云盘

**输入**：用户在发现页点击【我的云盘】卡片。

**输出**：按资源类型分文件夹展示的资源目录。

**展示形式**：标准文件目录形式，包含五个文件夹：
- 讲解文档
- 思维导图
- 练习题
- 拓展材料
- 代码案例

用户点击文件夹进入对应类型，浏览、查看所有已生成的个性化学习资源。

## 3.9 日程协作基础功能

- **图片OCR日程识别**：拍照/相册截图自动提取日程信息，批量导入日历
- **个人日程管理**：创建/编辑/删除、日历视图查看、日程搜索，支持离线使用
- **多层级群组协作**：群组/子群组创建、成员审批、日程批量下发同步
- **用户与反馈管理**：手机号登录、意见反馈、消息通知推送

# 4. 输出质量标准

从四个维度定义AI学习系统的质量要求。

## 4.1 画像质量

- **采集完整率**：六维画像数据完整率≥95%，无缺失维度
- **准确性**：画像特征与用户实际学情匹配，无明显偏差
- **时效性**：支持画像随学随新，用户学习行为变化后画像及时更新

## 4.2 资源生成质量

- **生成成功率**：五类资源生成成功率≥90%
- **个性化适配**：资源内容与用户画像（知识基础、薄弱点、学习风格）匹配，非千人一面
- **内容准确性**：生成的学术内容无事实性错误，无AI幻觉
- **流式体验**：流式输出适配移动端标准，无长时间白屏等待

## 4.3 学习规划与答疑质量

- **路径适配准确率**：生成的学习路径与用户目标、时间、能力匹配度≥85%
- **答疑有效解决率**：答疑内容能有效解答用户问题的比例≥90%
- **多模态表达**：复杂知识点自动配可视化图解，辅助理解

## 4.4 系统性能与安全

- **AI模块崩溃率**：＜0.1%
- **响应速度**：页面加载、资源生成响应速度符合移动端使用标准
- **内容安全**：内置防幻觉、内容审核机制，杜绝虚假、违规学术内容
- **数据安全**：用户画像、学习记录、账号信息全程加密存储
