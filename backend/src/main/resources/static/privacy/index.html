一、隐私政策导言

时纪流是一款简洁高效的个人日程管理应用。我们高度重视您的个人信息保护，本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

运营主体：舟山市时纪云人工智能应用软件有限责任公司

二、我们如何收集和使用您的个人信息

1. 收集目的：我们收集您的个人信息以便为您提供日程管理、群组共享、拍照识别等服务。

2. 收集信息类型：
• 账户信息（用户名、手机号码）
• 设备信息（设备型号、操作系统）
• 日历信息（您创建的日程内容）
• 位置信息（用于日程地点设置）
• 相机权限（用于拍照识别日程）

3. 个人信息存储：您的数据存储在中国大陆地区的服务器上，我们采用加密措施保护您的个人信息安全。

4. 保留期限：您的个人信息将在您注销账户后15个工作日内删除。

三、我们如何使用 Cookie 和同类技术

我们使用本地存储技术来保存您的偏好设置，如主题模式等。您可以通过设备设置管理相关权限。

四、我们如何共享、转让您的个人信息

1. 群组共享：当您加入群组并分享日程时，您的日程信息将展示给群组成员。

2. 第三方SDK：我们使用的第三方服务包括阿里云短信服务（用于验证码发送），该SDK可能收集必要的设备信息。

3. 未经您的同意，我们不会将您的个人信息转让给任何第三方。

五、我们如何保护您的信息

1. 数据加密：您的密码采用BCrypt加密存储。

2. 传输安全：所有数据传输采用HTTPS加密。

3. 访问审计：我们对用户数据的访问进行日志记录。

4. 已取得的安全认证：遵循行业标准的安全规范。

六、信息的存储

存储地点：中国大陆
存储期限：自收集日期起5年内，或直到您注销账户

2. 更正权：您可以修改您的昵称、手机号绑定。

3. 删除权：您可以注销账户，我们将在15个工作日内删除您的数据。

4. 撤回同意：您可以联系客服撤回同意。
